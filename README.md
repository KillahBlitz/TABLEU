# TABLEU - Enterprise Agile Kanban & KPI Platform

Sistema integral de gestión ágil visual con Tablero Kanban (4 columnas), Backlog, Épicas, Sprints, métricas de rendimiento (KPIs) por horas y dificultad, gobernado por un sistema estricto de roles (RBAC).

---

## Servicios Activos

- **Frontend (React + Vite + TSParticles):** [http://localhost:5173](http://localhost:5173)
- **Backend (Node.js + Express + MongoDB):** [http://localhost:5001](http://localhost:5001)
- **Health Check API:** [http://localhost:5001/api/health](http://localhost:5001/api/health)

---

## Inicio Rápido

1. **Backend:**
   ```bash
   cd backend
   npm install
   npm run dev
   ```
2. **Frontend:**
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
3. **Ejecutar Pruebas E2E:**
   ```bash
   cd backend
   node test_e2e_scenarios.js
   ```
